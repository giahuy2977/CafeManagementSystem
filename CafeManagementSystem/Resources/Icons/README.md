# Thư mục Icons & Tài nguyên đồ họa

Thư mục này dùng để lưu trữ các tệp icon (SVG, PNG) hoặc Vector Path phục vụ giao diện ứng dụng Cafe Management System.

## Quy chuẩn icon:
- Màu sắc biểu tượng ưu tiên sử dụng mã màu `#FFFFFF` (cho nút chính hoặc sidebar tối) hoặc `#4A2E1F` / `#7A4B2F` (cho các nút phụ trên nền sáng).
- Kích thước chuẩn: 16x16, 20x20 hoặc 24x24 px.
